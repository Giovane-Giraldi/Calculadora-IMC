#  Calculadora de IMC

Aplicação web desenvolvida para calcular o **Índice de Massa Corporal (IMC)** a partir do peso e da altura informados pelo usuário.

O projeto foi criado com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web, utilizando HTML, CSS, JavaScript e Bootstrap.

##  Funcionalidades

- Cálculo do IMC com base no peso e na altura.
- Validação de valores inválidos, negativos ou iguais a zero.
- Suporte à altura com vírgula ou ponto decimal.
- Exibição dinâmica do resultado na página.
- Formulário com campos obrigatórios.
- Botão para limpar os campos.

##  Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** personalização visual.
- **JavaScript:** cálculos, validações e manipulação do DOM.
- **Bootstrap 5:** estilização e componentes de interface.

##  Como funciona?

O cálculo do IMC utiliza a seguinte fórmula:

**IMC = Peso (kg) / Altura² (m)**

Por exemplo:

- Peso: 70 kg
- Altura: 1,75 m
- IMC: 22,86

O resultado é apresentado na própria página, com duas casas decimais.

##  Como executar

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` no navegador.
4. Informe os dados solicitados e clique em **Calcular IMC**.
